7.2.1Parallel adder ขนาด 4 บิต

รูปที่ 7.8 (ก) วงจรลอจิก (ข) สัญลักษณ์ · 4 บิต = nibble
ตารางที่ 7.3 ใช้ตารางของ full-adder ทีละบิต n = 1 → 4 โดย Cn−1 มาจากบิตก่อนหน้า
ตย. 7.3 1100 + 1100: n=1,2 → 0 · n=3 → Σ=0, C=1 · n=4 → Σ=1, C4=1 → 11000
ไอซีจริง: 74LS283 (4-bit binary full adder with fast carry)

ลองเอง: ตัวทดส่งต่อทีละบิต (ripple carry)

กด “ตย. 7.3” แล้วกด “ทีละขั้น” 4 ครั้ง ให้นักศึกษาบอกค่า Σ_n และ C_n ก่อนกดแต่ละครั้ง

7.3Comparator: ตรวจความเท่ากัน

ตัวอย่างที่ 7.4: (I) 10 กับ 10 → A = B · (II) 11 กับ 10 → A ≠ B · ถามต่อ: ขยายเป็น 4 บิตต้องเพิ่มอะไร (XOR 4 ตัว + AND 4 อินพุต)

7.3.2ตรวจความไม่เท่ากัน: A > B, A = B, A < B

รูปที่ 7.13 comparator 4 บิต

เริ่มจากบิตที่มีนัยสำคัญสูงสุด (A3, B3)

  • A3 = 1, B3 = 0 → A > B
  • A3 = 0, B3 = 1 → A < B
  • A3 = B3 → ตรวจบิตถัดไป ทำซ้ำจนถึง LSB

ลองในแบบจำลองหน้าก่อน: กด “4 บิต: ความไม่เท่ากัน”

ไอซีจริง: 7485 (4-bit magnitude comparator) มีขา cascade input สำหรับต่อขยาย

7.8Demultiplexer (data distributor)

รูปที่ 7.29 · DEMUX ใช้ขา data input ร่วมกับ AND ทุกตัว — วงจรเหมือน decoder ที่มีขา enable (74LS138 ใช้ได้ทั้งสองแบบ)

สรุปท้ายบท

  • Half-adder: Σ = A ⊕ B, Cout = AB · Full-adder เพิ่ม Cin = half-adder 2 ตัว + OR
  • Parallel adder: Cout บิตต่ำ → Cin บิตสูง · ขยายด้วยการ cascade
  • Comparator: XOR/XNOR + AND ตรวจ A = B · ความไม่เท่ากันเริ่มจาก MSB
  • Decoder: n อินพุต → 2n เอาต์พุต · 1-of-16, BCD-to-decimal, BCD-to-7-segment
  • Encoder: ตรงข้ามกับ decoder · decimal-to-BCD ด้วย OR · priority encoder สำหรับแป้นกด
  • Binary ⇄ Gray ด้วย XOR · MUX เลือกหลาย → หนึ่ง · DEMUX กระจายหนึ่ง → หลาย
