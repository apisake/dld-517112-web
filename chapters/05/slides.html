5.1ลดรูปด้วยพีชคณิตบูลีน · ตัวอย่างที่ 5.1

AB + A(B + C) + B(B + C) = AB + AB + AC + BB + BCกระจาย = AB + AB + AC + B + BCข้อ 7: BB = B = AB + AC + B + BCข้อ 5 = AB + AC + Bข้อ 10: B + BC = B = B + ACข้อ 10: AB + B = B
รูปที่ 5.1 · 5 เกท → 2 เกท ผลลัพธ์เหมือนกันทุกกรณี
ตัวอย่างที่ 5.2–5.4 อยู่ในแบบจำลองถัดไป — ให้นักศึกษาเดาขั้นถัดไปก่อนกด

5.2รูปแบบมาตรฐาน: SOP และ POS

Sum-of-products (SOP)
ผลบวกของพจน์การคูณ
AB + BCD + AC
วงจร AND-OR
Product-of-sums (POS)
ผลคูณของพจน์การบวก
(A + B)(B + C + D)(A + C)
วงจร OR-AND

โดเมน = เซตตัวแปรในนิพจน์ · มาตรฐาน = ทุกพจน์มีตัวแปรครบทุกตัวในโดเมน · ขีดคร่อมหลายตัวแปร เช่น ABC ไม่ใช่พจน์การคูณ

ตัวอย่างที่ 5.5: แปลงเป็น SOP ด้วยการกระจาย/DeMorgan

5.2ทำให้เป็นมาตรฐาน · ค่าไบนารีตัวแทน

SOP มาตรฐาน คูณด้วย (X + X) = 1
ABC = ABC(D + D) = ABCD + ABCD
ค่าไบนารี: พจน์การคูณ = 1 เมื่อ 1 → ตัวแปร, 0 → complement
ABCD ↔ 1010
POS มาตรฐาน บวก XX = 0 (ใช้ข้อ 12)
A + B + C = (A + B + C + D)(A + B + C + D)
ค่าไบนารี: พจน์การบวก = 0 เมื่อ 0 → ตัวแปร, 1 → complement
A + B + C + D ↔ 0101
SOP ↔ POS (ตย. 5.10): 000, 010, 011, 101, 111 ใน SOP → combination ที่เหลือ 001, 100, 110 คือ POS
(A + B + C)(A + B + C)(A + B + C)
ตัวอย่างที่ 5.6–5.10 ตรวจได้ในแบบจำลองถัดไป

ลองเอง: SOP มาตรฐาน ⇄ POS มาตรฐาน

ใช้กับแบบฝึกหัดที่ 5.2 · สังเกตว่า SOP + POS ครบทุก combination พอดี

5.3นิพจน์มาตรฐาน ⇄ ตารางค่าความจริง

  • SOP → ตาราง: ใส่ 1 ในแถวของแต่ละพจน์การคูณ ที่เหลือ 0 (ตย. 5.11)
  • POS → ตาราง: ใส่ 0 ในแถวของแต่ละพจน์การบวก ที่เหลือ 1 (ตย. 5.12)
  • ตาราง → SOP: แถวที่ได้ 1 → 1 = ตัวแปร, 0 = complement
  • ตาราง → POS: แถวที่ได้ 0 → 0 = ตัวแปร, 1 = complement
ค่าเริ่มต้นคือตารางที่ 5.3 (ตัวอย่างที่ 5.13) · คลิกเปลี่ยนเอาต์พุตแล้วดูนิพจน์เปลี่ยนตาม

5.4แผนผังคาร์โนห์ (Karnaugh Map)

รูปที่ 5.5 (ข) แผนผัง 4 ตัวแปร
  • จำนวน cell = 2ⁿ: 3 ตัวแปร = 8 · 4 ตัวแปร = 16
  • แถว AB · คอลัมน์ C หรือ CD เรียงแบบรหัสเกรย์ 00, 01, 11, 10
  • cell ที่ติดกัน (บน ล่าง ซ้าย ขวา) ต่างกัน 1 บิต — แนวทแยงไม่นับ
  • ขอบซ้าย–ขวา และบน–ล่าง ม้วนบรรจบกัน (รูปที่ 5.6)
ถามท้าย 5.4.1: ค่าไบนารี 010 อยู่ cell ไหนในแผนผัง 3 ตัวแปร?

ลองเอง: cell ใดบ้างที่ติดกัน

คลิกมุมทั้งสี่ (0000, 0010, 1000, 1010) — ให้อภิปรายว่าทั้งสี่มุมติดกันอย่างไร

5.5.3กฎการจัดกลุ่ม และการอ่านพจน์

  1. กลุ่มมี 1, 2, 4, 8, 16 cell
  2. cell ในกลุ่มต้องติดกัน
  3. กลุ่มใหญ่ที่สุด และน้อยกลุ่มที่สุด
  4. 1 ทุกตัวต้องอยู่ในกลุ่ม · ซ้อนกันได้ถ้าแต่ละกลุ่มมี 1 ที่ไม่ซ้ำ
กลุ่ม3 ตัวแปร4 ตัวแปร
1 cell3 ตัวแปร4 ตัวแปร
2 cell23
4 cell12

16 cell—= 1

อ่านพจน์: กำจัดตัวแปรขัดแย้ง (ตัวแปรที่มีทั้งปกติและ complement ในกลุ่ม)

ตัวอย่างที่ 5.18–5.20 · ตย. 5.19: B + AC + ACD

ลองเอง: แผนผังคาร์โนห์ลดรูป SOP

กด “จัดกลุ่มถัดไป” ทีละกลุ่ม · 5.21: กลุ่ม 4 cell ม้วนบรรจบบน–ล่างให้ B · 5.22: ม้วนสองแนวได้ D + BC · ลองคลิก cell เปลี่ยนค่าเอง

5.5.4–5.5.5จากตารางค่าความจริง · Don’t care

รูปที่ 5.9 (ข)

combination ที่ไม่มีวันเกิด เช่น BCD 1010–1111 → เขียน X

X เป็น 0 หรือ 1 ก็ได้ → นำไปร่วมกลุ่มเมื่อช่วยให้กลุ่มใหญ่ขึ้น

ไม่ใช้ X: ABC + ABCD
ใช้ X: A + BCD
แบบจำลองในหน้าเนื้อหาหัวข้อ 5.5.5 กดปุ่ม “รูป 5.9” ให้ผลทั้งสองแบบ

5.6ลดรูป POS: จัดกลุ่มของ 0

  • ใส่ 0 ใน cell ของแต่ละพจน์การบวก (ตย. 5.23)
  • จัดกลุ่ม 0 ด้วยกฎเดียวกับ SOP
  • อ่านพจน์การบวก: 0 → ตัวแปร, 1 → complement
  • ตย. 5.24: POS = A(B + C) · SOP ที่เทียบเท่า (จัดกลุ่ม 1) = AB + AC
ลองสลับโหมด SOP ⇄ POS ในแผนผังเดียวกันให้เห็นว่าได้นิพจน์ที่เทียบเท่ากัน · ตย. 5.25 = (C + D)(A + B + D)(A + B + C)

สรุปท้ายบท

  • ลดรูปด้วยกฎ หลักเกณฑ์ และ DeMorgan → เกทน้อยลง ผลลัพธ์เหมือนเดิม
  • SOP = ผลบวกของพจน์การคูณ · POS = ผลคูณของพจน์การบวก · มาตรฐาน = ตัวแปรครบโดเมน
  • ขยายพจน์: × (X + X) สำหรับ SOP · + XX สำหรับ POS · หรือ numerical expansion
  • แผนผังคาร์โนห์เรียงตามรหัสเกรย์ · cell ติดกันต่าง 1 บิต (รวมการม้วนบรรจบ)
  • กลุ่ม 1, 2, 4, 8, 16 ให้ใหญ่และน้อยที่สุด → กำจัดตัวแปรขัดแย้ง · กลุ่ม 1 → SOP · กลุ่ม 0 → POS
  • don’t care (X) ร่วมกลุ่มได้เพื่อลดรูปให้เล็กลงอีก
มอบหมาย: แบบฝึกหัดที่ 5.1–5.5 และแบบทดสอบท้ายบท · สัปดาห์หน้าเป็นบทสุดท้ายก่อนสอบกลางภาค
