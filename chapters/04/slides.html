พีชคณิตบูลีน = คณิตศาสตร์ของระบบดิจิทัล

4.2Variable · Complement · Literal

Variable
อักษรพิมพ์ใหญ่แทนปริมาณทางลอจิก มีค่า 0 หรือ 1
Complement
นิเสธของ variable: A (“เอบาร์” / “น็อตเอ”) หรือ A′
Literal
variable หรือ complement ของ variable เช่น A, B
Sum term (OR) เช่น A + B + C
= 1 เมื่อ literal ใดเป็น 1 · = 0 เมื่อทุก literal เป็น 0
Product term (AND) เช่น ABC
= 1 เมื่อทุก literal เป็น 1 · = 0 เมื่อ literal ใดเป็น 0
ตัวอย่างที่ 4.1: A + B + C + D = 0 เมื่อ A=0, B=1, C=0, D=1 · ตัวอย่างที่ 4.2: ABCD = 1 เมื่อ A=1, B=0, C=1, D=0

ลองเอง: Sum term และ Product term

ให้นักศึกษาตอบก่อนว่าต้องตั้งค่าอะไร แล้วกดตรวจ

4.3.1กฎพื้นฐาน 3 กฎ

สลับที่A + B = B + AAB = BA(4.1, 4.2)
เปลี่ยนกลุ่มA + (B + C) = (A + B) + CA(BC) = (AB)C(4.3, 4.4)
กระจายA(B + C) = AB + AC(4.5)
รูปที่ 4.5 กฎการกระจายกับวงจรเกท · ทางกลับกันคือการแยกแฟกเตอร์ AB + AC = A(B + C)
เหมือนพีชคณิตทั่วไป · ใช้ได้กับตัวแปรกี่ตัวก็ได้

ลองเอง: พิสูจน์ด้วยตารางค่าความจริง

กดปุ่ม “ลองข้อผิด” ให้เห็นว่า A + BC ≠ (A + B)C — แล้วถามว่าวงเล็บไหนที่เท่ากับ A + BC (→ หลักเกณฑ์ข้อ 12)

4.3.2หลักเกณฑ์พื้นฐาน 12 ข้อ (ตารางที่ 4.1)

1A + 0 = A
2A + 1 = 1
3A · 0 = 0
4A · 1 = A
5A + A = A
6A + A = 1
7A · A = A
8A · A = 0
9A = A
10A + AB = A
11A + AB = A + B
12(A + B)(A + C) = A + BC

A, B, C แทนตัวแปรเดี่ยว หรือกลุ่มของตัวแปร ก็ได้

ข้อ 1–9 เห็นได้จากเกทหนึ่งตัว (รูปที่ 4.6–4.14) · ข้อ 10–12 ต้องพิสูจน์ ให้นักศึกษาท่องให้ได้ — ใช้ทุกครั้งในบทที่ 5

ข้อ 1–9 มองเป็นเกทหนึ่งตัว

ข้อ 1: A + 0 = A
ข้อ 2: A + 1 = 1
ข้อ 3: A · 0 = 0
ข้อ 6: A + A = 1
ข้อ 8: A · A = 0
ข้อ 9: complement สองชั้น = A
โยงบทที่ 3 หัวข้อ 3.7.8: อินพุตที่ไม่ใช้ของ AND ต่อ VCC (ข้อ 4: A·1 = A) และของ OR ต่อ GND (ข้อ 1: A+0 = A)

พิสูจน์ข้อ 10 และ 11

A + AB= A(1 + B)กฎการกระจาย = A · 1ข้อ 2 = Aข้อ 4
A + AB= (A + AB) + ABข้อ 10 = (AA + AB) + ABข้อ 7 = AA + AB + AA + ABข้อ 8 (+0) = (A + A)(A + B)แยกแฟกเตอร์ = 1 · (A + B)ข้อ 6 = A + Bข้อ 4
ข้อ 12 พิสูจน์ในหน้าเนื้อหา: (A+B)(A+C) = AA + AC + AB + BC = A + AC + AB + BC = A(1+C) + AB + BC = A + AB + BC = A(1+B) + BC = A + BC

ลองเอง: หลักเกณฑ์ 12 ข้อ

ข้อ 1–9 กดเปลี่ยน A ดูเกท · ข้อ 10–12 ดูคอลัมน์ระหว่างทางในตาราง (ตารางที่ 4.2–4.4)

4.4ทฤษฎีบทของ DeMorgan

ทฤษฎีบทแรก
complement ของผลคูณ = ผลบวกของ complement แต่ละตัว
XY = X + Y
สมการที่ 4.6 · NAND ≡ Negative-OR
ทฤษฎีบทที่สอง
complement ของผลบวก = ผลคูณของ complement แต่ละตัว
X + Y = XY
สมการที่ 4.7 · NOR ≡ Negative-AND
หลักจำ: “ทลายเส้น bar แล้วเปลี่ยนเครื่องหมาย” (· ↔ +) · ใช้ได้กับกี่ตัวแปรก็ได้:
XYZ = X + Y + Z · W + X + Y + Z = WXYZ
ตัวอย่างที่ 4.3–4.4 · รูปที่ 4.15 เทียบเกทและตารางค่าความจริง · X, Y เป็นพจน์ก็ได้ เช่น complement ของ (AB + C)(A + BC)

4.4.1ขั้นตอนการใช้ DeMorgan

  1. กำหนดพจน์ใหญ่ให้เป็นตัวแปรเดี่ยว X, Y
  2. ใช้ DeMorgan กับเส้น bar ที่อยู่นอกสุดก่อน
  3. bar ซ้อนสองชั้นหักล้างด้วยข้อ 9 (ไม่ใช่ DeMorgan)
  4. ทำซ้ำกับพจน์ที่ยังมี bar คร่อมกลุ่ม จนเหลือ bar บนตัวแปรเดี่ยว
ตัวอย่างที่ 4.7 หา XNOR จาก XOR
complement(AB + AB) = (A + B)(A + B) = AA + AB + AB + BB = AB + AB
ตัวอย่างที่ 4.5–4.6 ให้ทำบนกระดาษก่อน แล้วตรวจด้วยแบบจำลองถัดไป

ลองเอง: ทลายเส้น bar ทีละขั้น

กดตัวอย่าง 4.4.1 แล้วกดขั้นถัดไปทีละขั้น ถามก่อนทุกขั้นว่าใช้กฎอะไร · ทุกขั้นมี ✓ = ยังเทียบเท่านิพจน์เดิม

4.5วิเคราะห์วงจรลอจิกด้วยพีชคณิตบูลีน

  1. เริ่มจากเกทซ้ายสุด (ใกล้อินพุต)
  2. AND: CD
  3. OR: B + CD
  4. AND: A(B + CD)
วงจรที่ผสานเกทหลายตัว = วงจรคอมบิเนชัน (บทที่ 6 จะวิเคราะห์อย่างเป็นระบบ)

ลองเอง: วงจร → นิพจน์

กดเกทถัดไปทีละเกท แล้วเปลี่ยนอินพุตให้ X = 1 ทั้งสองเงื่อนไข

4.5.2ประเมินนิพจน์ → ตารางค่าความจริง

A(B + CD) = 1 ก็ต่อเมื่อ A = 1 และ B + CD = 1

① A = 1 และ B = 1 (C, D อะไรก็ได้) → 4 แถว
② A = 1 และ C = D = 1 (B อะไรก็ได้) → 2 แถว

ซ้ำที่ ABCD = 1111 → รวม 5 แถว ที่เหลือเป็น 0

ลองเอง: สร้างตารางค่าความจริง

เปิดโหมด “ลองเติมเอง” ให้นักศึกษาเติมคอลัมน์เอาต์พุตทีละแถว แล้วตรวจ · ลองนิพจน์ XOR/XNOR

สรุปท้ายบท

  • บูล (1854) → แชนนอน (1938) นำมาใช้กับวงจรสวิตช์
  • การบวก = OR (sum term = 0 เมื่อทุก literal = 0) · การคูณ = AND (product term = 1 เมื่อทุก literal = 1)
  • กฎสลับที่ · เปลี่ยนกลุ่ม · กระจาย A(B + C) = AB + AC
  • หลักเกณฑ์ 12 ข้อ เช่น A + A = 1, AA = 0, A + AB = A, A + AB = A + B, (A + B)(A + C) = A + BC
  • DeMorgan: XY = X + Y · X + Y = XY
  • วิเคราะห์วงจร: เขียนนิพจน์ทีละเกทจากอินพุตไปเอาต์พุต → ประเมิน → ตาราง 2ⁿ แถว
