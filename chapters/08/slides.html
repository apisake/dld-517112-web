8.1.1S-R (Set-Reset) latch

(ก) NOR · อินพุต active-HIGH
(ข) NAND · อินพุต active-LOW (S, R)

เอาต์พุตของเกทหนึ่งป้อนกลับเป็นอินพุตของอีกเกท → bistable จำสถานะได้ 2 แบบ

แลทช์ = อุปกรณ์เก็บข้อมูลชั่วคราว (temporary storage) · ให้นักศึกษาไล่ค่าในวงจร NOR เมื่อ S = R = 0 ว่ามีได้สองสถานะ

ลองเอง: S-R latch จำค่าได้อย่างไร

ลำดับสาธิต: S = 1 → SET · S = 0 → ยังเป็น 1 (จำ) · R = 1 → RESET · S = R = 1 → invalid · สลับเป็น NAND แล้วทำซ้ำ

ตัวอย่างที่ 8.1 · S-R latch กับผังเวลา

  • S เปลี่ยน 1 → 0: active → SET (Q = 1) · S กลับเป็น 1: Q คงเดิม
  • R เปลี่ยน 1 → 0: active → RESET (Q = 0) · R กลับเป็น 1: Q คงเดิม
ให้นักศึกษาวาด Q เองก่อน 3 นาที โดยเริ่มจาก Q = LOW · การประยุกต์: วงจรกันเด้งของสวิตช์ (ปฏิบัติการข้อ 2)

8.1.2Gated S-R latch

(ก) ผังวงจร
(ข) สัญลักษณ์

เพิ่มขา EN (enable) ด้วย AND/NAND ขวางอินพุตไว้

  • EN = 1 → ทำงานเหมือน S-R latch
  • EN = 0 → S, R ไม่มีผล คงสภาวะเดิม
ยังมีสภาวะ invalid เมื่อ S = R = 1 ขณะ EN = 1

ลองเอง: Gated S-R latch

คลิกให้ S = R = 1 ในช่วง EN = 1 เพื่อดู invalid (พื้นแดง) · ในช่วง EN = 0 เปลี่ยน S, R ได้โดย Q ไม่เปลี่ยน

8.1.3Gated D latch

(ก) D → S และ D → R ผ่าน inverter

อินพุตเดียว D (Data) · S และ R ไม่มีวันเท่ากัน → ไม่มี invalid

  • EN = 1 → Q = D (โปร่งใส · transparent)
  • EN = 0 → จำค่า D ล่าสุดไว้

ลองเอง: Gated D latch

ชี้ว่าในช่วงที่ระบายพื้น Q ลอกรูปคลื่น D ทุกการเปลี่ยนแปลง — นี่คือปัญหาที่ฟลิปฟลอปแก้

สรุปท้ายบท

  • แลทช์ = bistable ที่ใช้การป้อนกลับ · S-R (NOR, active-HIGH) / S-R (NAND, active-LOW) มี invalid
  • Gated latch เพิ่ม EN (ทำงานตามระดับ) · D latch ไม่มี invalid
  • ฟลิปฟลอปเปลี่ยนเฉพาะที่ขอบนาฬิกา ↑ หรือ ↓ (dynamic input indicator)
  • D FF เก็บ 1 บิต · J-K FF: SET / RESET / NC / toggle
  • PRE / CLR เป็น asynchronous — บังคับ Q ทันที
  • ประยุกต์: เก็บข้อมูลแบบขนาน · หารความถี่ 2n · วงจรนับไบนารี
