บทที่ 9

จุดประสงค์

  1. อธิบายความแตกต่างระหว่าง counter แบบ asynchronous และ synchronous
  2. วิเคราะห์ผังเวลาและวงจรของ counter · ผลของ propagation delay
  3. กำหนด modulus · แยกแยะ binary counter 4 บิตกับ decade counter
  4. ใช้ up/down counter สร้างลำดับไปข้างหน้าและย้อนหลัง
  5. ออกแบบวงจร synchronous counter เบื้องต้น
  6. รู้จักชิฟต์รีจิสเตอร์ (SISO, SIPO, PISO, PIPO)

9.1ประเภทของวงจรนับ

Asynchronous (ripple)
  • นาฬิกาภายนอกเข้า FF0 ตัวเดียว
  • เอาต์พุตตัวก่อนหน้าเป็นนาฬิกาของตัวถัดไป
  • ฟลิปฟลอปเปลี่ยนสถานะไม่พร้อมกัน · delay สะสม
Synchronous
  • นาฬิกาเดียวกันเข้าทุกตัว
  • ใช้เกตสร้างเงื่อนไข toggle (J = K)
  • ทุกบิตเปลี่ยนพร้อมกัน · เร็วกว่า

ฟลิปฟลอป n ตัว → maximum modulus = 2n สถานะ

9.2.2Asynchronous counter ขนาด 3 บิต

รูปที่ 9.3
รูปที่ 9.4 นับ 0–7 แล้ว recycle · ตัวอย่างที่ 9.1 ต่อเป็น 4 บิตด้วยขอบขาลง (นับ 0–15)

ลองเอง: ripple counter

เปลี่ยนเป็น 2, 3, 4 บิต แล้วให้นักศึกษาบอก modulus · ยังไม่ปรับ delay

9.2.3Propagation delay

รูปที่ 9.5 ripple counter 3 บิต

ฟลิปฟลอปแต่ละตัวต้องใช้เวลา tPLH / tPHL ก่อนเอาต์พุตเปลี่ยน

  • ตัวหลังต้องรอตัวก่อนหน้า → delay สะสม
  • ระหว่างทางเกิดสถานะชั่วคราว เช่น 011 → 010 → 000 → 100
  • จำกัดความถี่สูงสุดของนาฬิกา · ถอดรหัสผิดชั่วขณะได้
สลับไปหน้าถัดไปแล้วเลื่อน delay ให้เห็นสถานะชั่วคราวที่ขอบนาฬิกาลูกที่ 4 และ 8

ลองเอง: ผลของ propagation delay

9.2.4Modulus และวงจรนับสิบ (MOD10)

รูปที่ 9.6 (ก) NAND รับ Q3, Q1 → CLR

modulus = จำนวนสถานะที่วงจรนับผ่าน · 2n = maximum

truncated sequence: บังคับ recycle ก่อนครบ เช่น MOD10 (decade/BCD) 0–9

partial decoding: 1010 เป็นสถานะแรกที่ Q3 = Q1 = 1

เกิด glitch บน Q1 เพราะ 1010 ปรากฏชั่วขณะก่อนถูกล้าง · MOD12 ใช้ Q3, Q2 (รูปที่ 9.7)

ลองเอง: MOD10 / MOD12 แบบ asynchronous

ตั้ง delay = 0 แล้วถามว่า glitch หายจริงหรือ (ในอุดมคติกว้าง 0 แต่ของจริงมีเสมอ)

9.3.1Synchronous counter ขนาด 2 บิต

รูปที่ 9.8 CLK ร่วมกัน · J1 = K1 = Q0
  • FF0: J = K = 1 → toggle ทุกขอบ
  • FF1: toggle เฉพาะเมื่อ Q0 = 1 ก่อนขอบนาฬิกา
  • ทุกตัวเปลี่ยนพร้อมกัน (ห่างเพียง delay ของตัวเอง)
รูปที่ 9.10
รูปที่ 9.9 แสดงรายละเอียดทีละขอบนาฬิกา — ให้เน้นว่า FF1 ดูค่า Q0 “ก่อน” ขอบ ไม่ใช่หลังขอบ

9.3.2–9.3.3Synchronous counter 3 และ 4 บิต

รูปที่ 9.11 · J2 = K2 = Q1Q0
รูปที่ 9.12 · J3 = K3 = Q2Q1Q0

กฎ: บิตที่ k toggle เมื่อทุกบิตที่ต่ำกว่าเป็น 1 → AND ของ Q0…Qk−1

ลองเอง: synchronous binary counter

กดทีละพัลส์ — ก่อนกดให้นักศึกษาบอกว่า FF ใดจะ toggle (ช่องสีเขียว)

9.3.4BCD decade synchronous counter

รูปที่ 9.13 · กด ×4 สองครั้งจนถึง 1001 แล้วถามว่าพัลส์ถัดไปเป็นอะไร และเพราะอะไร

9.3.5Up/Down synchronous counter

รูปที่ 9.14

J0 = K0 = 1

J1 = K1 = Q0·UP + Q0·DOWN

J2 = K2 = Q1Q0·UP + Q1Q0·DOWN

นับขึ้น: toggle เมื่อบิตต่ำกว่าเป็น 1 ทั้งหมด · นับลง: เมื่อเป็น 0 ทั้งหมด (รูปที่ 9.15)

ลองเอง: นับขึ้น/ลง

9.4.1โมเดลทั่วไปของวงจรซีเควนเชียล

รูปที่ 9.16

วงจรคอมไบเนชัน + หน่วยความจำ (ฟลิปฟลอป)

  • present state: ค่าที่ฟลิปฟลอปเก็บอยู่
  • วงจรคอมไบเนชันคำนวณอินพุต J, K → next state
  • ขอบนาฬิกาทำให้ next state กลายเป็น present state
โมเดลนี้ใช้ต่อในบทที่ 10 (Mealy/Moore)

9.4.2ออกแบบวงจรนับ 6 ขั้นตอน

  1. ผังสถานะ (state diagram)
  2. ตารางสถานะถัดไป (next-state)
  3. ตาราง transition ของฟลิปฟลอป
  4. แผนผังคาร์โนห์ (สถานะที่ไม่ใช้ = X)
  5. นิพจน์ของ J, K
  6. สร้างวงจร
QN → QN+1JK
0 → 00X
0 → 11X
1 → 0X1
1 → 1X0

ตารางที่ 9.5 transition ของ J-K

รูปที่ 9.17 Gray code 3 บิต

ลองเอง: ออกแบบวงจรนับรหัสเกรย์

ไล่แท็บ 1 → 6 · ขั้นที่ 5 ได้ J0 = Q2Q1 + Q2Q1 (XNOR), K0 = XOR, J1 = Q2Q0, K1 = Q2Q0, J2 = Q1Q0, K2 = Q1Q0 — วงจรรูปที่ 9.20

ตัวอย่างที่ 9.2: นับ 1 → 2 → 5 → 7

สถานะ 0, 3, 4, 6 เป็น X · ผล: J0 = 1, K0 = Q2, J1 = K1 = 1, J2 = K2 = Q1 · ขั้นที่ 6 ดูว่า 011 ไป 000 แล้วไม่เข้าลำดับ — ถามว่าแก้อย่างไร

9.5ชิฟต์รีจิสเตอร์ (shift register)

รูปที่ 9.21 ฟลิปฟลอป = ที่เก็บ 1 บิต (1 stage)
รูปที่ 9.22 ทิศทางการเลื่อนข้อมูล

ใช้จัดเก็บและเคลื่อนย้ายข้อมูล · ความจุ = จำนวน stage

9.5.1SISO: Serial In / Serial Out

รูปที่ 9.23 · ข้อมูลเลื่อน 1 stage ต่อ 1 พัลส์
โหลด 4 บิต (1010) ต้องใช้ 4 พัลส์ · อ่านออกอีก 4 พัลส์
สัญลักษณ์ SRG 8 = SISO ขนาด 8 บิต (รูปที่ 9.25)

ลองเอง: SISO / SIPO / PISO / PIPO

SISO ป้อน 1010 ครบ 4 พัลส์ (รูปที่ 9.24) แล้วกดต่ออีก 4 เพื่ออ่านออก · สลับ PISO: LOAD 1 พัลส์ แล้ว SHIFT

9.5.2–9.5.4SIPO · PISO · PIPO

SIPO: อนุกรม → ขนาน
PISO: ขนาน → อนุกรม (SHIFT/LOAD)
PIPO: ขนาน → ขนาน (1 พัลส์)
การประยุกต์: แปลงข้อมูลอนุกรม/ขนาน (เช่น UART, ขยายขาเอาต์พุตด้วย 74HC595)

สรุปท้ายบท

  • ฟลิปฟลอป n ตัว → maximum modulus 2n · แบ่งเป็น asynchronous / synchronous
  • Asynchronous: นาฬิกาเข้า FF0 ตัวเดียว · delay สะสม เกิดสถานะชั่วคราว
  • Truncated (MOD10, MOD12): NAND ถอดรหัสบางส่วน → CLR · เกิด glitch
  • Synchronous: นาฬิกาเดียวกัน · AND สร้างเงื่อนไข toggle · up/down ด้วยบิตควบคุม
  • ออกแบบ 6 ขั้นตอน: ผังสถานะ → next-state → transition → คาร์โนห์ → นิพจน์ → วงจร
  • ชิฟต์รีจิสเตอร์: SISO · SIPO · PISO · PIPO
