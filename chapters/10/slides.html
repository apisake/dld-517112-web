10.1แบบจำลองวงจรเชิงลำดับ: Mealy กับ Moore

(ข) Moore: เอาต์พุต = f(สถานะ)

10.4.3สถานะที่ไม่ใช้และ self-starting

เลือก “เริ่ม: 010” แล้วกดพัลส์ — วนกับ 101 (lock-up) · สลับ “แก้ D1” แล้วทำซ้ำ — กลับเข้าวงภายในสองคาบ · ตัวอย่างที่ 10.5 รหัส 11 กลับเข้าลำดับเอง (รูปที่ 10.22)

สรุปท้ายบท

  • เครื่องสถานะ = ตรรกะสถานะถัดไป + ฟลิปฟลอป + ตรรกะเอาต์พุต · Mealy (x / y บนลูกศร) · Moore (สถานะ / เอาต์พุต)
  • คุณลักษณะใช้วิเคราะห์ · excitation ใช้ออกแบบ (D = Q+)
  • วิเคราะห์: สมการ → สมการสถานะถัดไป → ตารางสถานะ → ผังสถานะ → ผังเวลา
  • ออกแบบ: ผังสถานะ → ตาราง → ลดสถานะ → กำหนดรหัส → excitation → คาร์โนห์ → วงจร → ตรวจสอบ
  • fmax = 1 / (tpd,FF + tcomb(max) + tsu) · ตรวจ hold time ด้วยเส้นทางสั้นสุด
  • ตรวจทุกสถานะที่ไม่ใช้ · ถ้า lock-up ให้แก้สมการให้กลับเข้าลำดับ
