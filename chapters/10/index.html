10.1 แบบจำลองวงจรเชิงลำดับแบบซิงโครนัส

ในบทที่ 8 และบทที่ 9 เราได้รู้จักฟลิปฟลอปและการนำฟลิปฟลอปหลายตัวมาต่อกันเป็นวงจรนับและชิฟต์รีจิสเตอร์ ซึ่งเป็นวงจรเชิงลำดับ (sequential circuit) ที่มีรูปแบบการทำงานเฉพาะ ในบทนี้จะขยายแนวคิดดังกล่าวไปสู่วงจรเชิงลำดับแบบซิงโครนัสในรูปทั่วไป ซึ่งมักเรียกว่าเครื่องสถานะจำกัด (finite state machine, FSM) โดยจะศึกษาทั้งการวิเคราะห์ (analysis) คือการหาว่าวงจรที่กำหนดให้ทำงานอย่างไร และการออกแบบ (design) คือการสร้างวงจรจากคำอธิบายการทำงานที่ต้องการ

10.1.1 สถานะปัจจุบันและสถานะถัดไป

เอาต์พุตของวงจรคอมไบเนชันขึ้นอยู่กับอินพุตในขณะนั้นเท่านั้น แต่เอาต์พุตของวงจรเชิงลำดับขึ้นอยู่กับ “ประวัติ” ของอินพุตที่ผ่านมาด้วย ข้อมูลที่วงจรจดจำไว้นี้เก็บอยู่ในฟลิปฟลอป ค่าของฟลิปฟลอปทุกตัวรวมกันเรียกว่าสถานะ (state) ของวงจร วงจรที่มีฟลิปฟลอป n ตัวจะมีสถานะได้มากที่สุด 2n สถานะ

  • สถานะปัจจุบัน (present state) คือค่าที่ฟลิปฟลอปเก็บอยู่ในคาบสัญญาณนาฬิกาปัจจุบัน เขียนแทนด้วย Q1, Q0, …
  • สถานะถัดไป (next state) คือค่าที่ฟลิปฟลอปจะรับเข้าไปเมื่อเกิดขอบขาขึ้นของสัญญาณนาฬิกาครั้งถัดไป ในบทนี้เขียนแทนด้วย Q1+, Q0+, … (ในตำราบางเล่มเขียนเป็น Q(t + 1))

ในวงจรแบบซิงโครนัส ฟลิปฟลอปทุกตัวใช้สัญญาณนาฬิกาเดียวกัน สถานะจึงเปลี่ยนพร้อมกันเฉพาะที่ขอบสัญญาณนาฬิกา ระหว่างขอบสัญญาณนาฬิกาสองครั้ง วงจรคอมไบเนชันจะคำนวณสถานะถัดไปและเอาต์พุตจากสถานะปัจจุบันและอินพุต ดังนั้นเราจึงพิจารณาการทำงานของวงจรเป็น “รอบ” ทีละคาบสัญญาณนาฬิกาได้

10.1.2 Mealy machine และ Moore machine

วงจรเชิงลำดับแบบซิงโครนัสประกอบด้วย 3 ส่วน ได้แก่ (1) ตรรกะสถานะถัดไป (next-state logic) ซึ่งเป็นวงจรคอมไบเนชันที่สร้างสัญญาณป้อนให้อินพุตของฟลิปฟลอป (2) รีจิสเตอร์สถานะ (state register) คือฟลิปฟลอปที่เก็บสถานะ และ (3) ตรรกะเอาต์พุต (output logic) ซึ่งเป็นวงจรคอมไบเนชันที่สร้างเอาต์พุต การแบ่งประเภทของเครื่องสถานะขึ้นอยู่กับว่าตรรกะเอาต์พุตรับสัญญาณจากที่ใด ดังรูปที่ 10.1

  • Mealy machine — เอาต์พุตเป็นฟังก์ชันของสถานะปัจจุบันและอินพุต เอาต์พุตจึงเปลี่ยนได้ทันทีเมื่ออินพุตเปลี่ยน โดยไม่ต้องรอขอบสัญญาณนาฬิกา
  • Moore machine — เอาต์พุตเป็นฟังก์ชันของสถานะปัจจุบันเท่านั้น เอาต์พุตจึงเปลี่ยนเฉพาะหลังขอบสัญญาณนาฬิกา และคงที่ตลอดคาบ

ในการเขียนผังสถานะ (state diagram) วงกลมแทนสถานะ และลูกศรแทนการเปลี่ยนสถานะที่เกิดขึ้นที่ขอบสัญญาณนาฬิกา สำหรับ Mealy machine ป้ายบนลูกศรเขียนในรูป อินพุต/เอาต์พุต เช่น 1/0 หมายถึง “เมื่ออินพุตเป็น 1 เอาต์พุตในรอบนี้เป็น 0 และสถานะจะเปลี่ยนไปตามลูกศร” ส่วน Moore machine เขียนเอาต์พุตไว้ในวงกลมคู่กับชื่อสถานะ เช่น S3/1 และป้ายบนลูกศรมีเฉพาะค่าอินพุต

10.1.3 สมการคุณลักษณะและตาราง excitation

เครื่องมือสำคัญที่ใช้ทั้งในการวิเคราะห์และการออกแบบมีสองอย่าง อย่างแรกคือสมการคุณลักษณะ (characteristic equation) ซึ่งบอกสถานะถัดไปจากอินพุตของฟลิปฟลอปและสถานะปัจจุบัน ใช้ในการวิเคราะห์ นอกจาก D และ J-K flip-flop ที่ได้ศึกษาในบทที่ 8 แล้ว ในบทนี้จะใช้ T flip-flop (toggle flip-flop) ด้วย ซึ่งก็คือ J-K flip-flop ที่ต่อ J และ K เข้าด้วยกันเป็นอินพุต T เมื่อ T = 0 เอาต์พุตคงเดิม และเมื่อ T = 1 เอาต์พุตกลับค่า (toggle) สัญลักษณ์ของฟลิปฟลอปทั้งสามชนิดแสดงในรูปที่ 10.2 และตารางคุณลักษณะแสดงในตารางที่ 10.1

10.2 การวิเคราะห์วงจรเชิงลำดับ

การวิเคราะห์วงจรเชิงลำดับแบบซิงโครนัสคือการหาพฤติกรรมของวงจรจากแผนภาพวงจรที่กำหนด มีขั้นตอนดังนี้

  1. เขียนสมการอินพุตของฟลิปฟลอป (excitation equation) และสมการเอาต์พุต จากวงจรคอมไบเนชัน ในรูปของสถานะปัจจุบันและอินพุต
  2. หาสมการสถานะถัดไป (next-state equation) โดยแทนสมการในขั้นที่ 1 ลงในสมการคุณลักษณะของฟลิปฟลอปแต่ละชนิด
  3. สร้างตารางสถานะ (state table) โดยคำนวณสถานะถัดไปและเอาต์พุตสำหรับทุกสถานะปัจจุบันและทุกค่าอินพุต
  4. วาดผังสถานะ (state diagram) จากตารางสถานะ
  5. วาดผังเวลา (timing diagram) สำหรับลำดับอินพุตตัวอย่าง แล้วสรุปความหมายของการทำงานของวงจร

10.3 การออกแบบวงจรเชิงลำดับ

การออกแบบเป็นกระบวนการย้อนกลับของการวิเคราะห์ เริ่มจากคำอธิบายการทำงานด้วยถ้อยคำ แล้วจบที่แผนภาพวงจร หัวข้อ 9.4 ได้แสดงกระบวนการนี้สำหรับวงจรนับซึ่งไม่มีอินพุตภายนอก ในหัวข้อนี้จะขยายไปสู่วงจรที่มีอินพุตและเอาต์พุตในรูปทั่วไป

10.3.1 ขั้นตอนการออกแบบ

  1. ทำความเข้าใจข้อกำหนด ระบุอินพุต เอาต์พุต และเลือกว่าจะใช้แบบ Mealy หรือ Moore
  2. สร้างผังสถานะ กำหนดสถานะให้แต่ละสถานะแทน “สิ่งที่วงจรต้องจำ” แล้วเขียนลูกศรของทุกค่าอินพุตจากทุกสถานะ
  3. สร้างตารางสถานะ จากผังสถานะ
  4. ลดจำนวนสถานะ (state reduction) รวมสถานะที่สมมูลกัน
  5. กำหนดรหัสสถานะ (state assignment) ให้แต่ละสถานะเป็นรหัสไบนารีของฟลิปฟลอป
  6. เลือกชนิดฟลิปฟลอปและสร้างตาราง excitation ด้วยตารางที่ 10.2 รหัสที่ไม่ได้ใช้ให้เป็น don’t care
  7. ลดรูปด้วยแผนผังคาร์โนห์ หาสมการอินพุตของฟลิปฟลอปและสมการเอาต์พุต
  8. วาดวงจร
  9. ตรวจสอบ วิเคราะห์วงจรที่ได้ย้อนกลับ (หรือจำลองการทำงาน) เทียบกับข้อกำหนด และตรวจสถานะที่ไม่ใช้ว่าวงจรกลับเข้าสู่ลำดับการทำงานปกติได้

10.3.2 การลดจำนวนสถานะ

สถานะสองสถานะสมมูลกัน (equivalent) เมื่อสำหรับทุกลำดับอินพุต วงจรที่เริ่มจากสถานะทั้งสองให้ลำดับเอาต์พุตเหมือนกันทุกประการ เราจึงรวมสถานะทั้งสองเป็นสถานะเดียวได้โดยพฤติกรรมภายนอกไม่เปลี่ยน วิธีที่ง่ายที่สุดคือการจับคู่แถว (row matching) โดยหาแถวในตารางสถานะที่มีทั้งสถานะถัดไปและเอาต์พุตเหมือนกันทุกค่าอินพุต แล้วตัดแถวหนึ่งทิ้ง แทนชื่อสถานะที่ถูกตัดด้วยสถานะที่เหลือทุกแห่งในตาราง และทำซ้ำจนไม่มีแถวที่ซ้ำกัน (วิธีนี้หาสถานะสมมูลได้ไม่ครบทุกกรณี วิธีทั่วไปคือ implication chart หรือ partition refinement ซึ่งอยู่นอกขอบเขตของบทนี้)

10.3.4 วงจรตรวจจับลำดับบิต 101

วงจรตรวจจับลำดับ (sequence detector) รับข้อมูลอนุกรมทีละบิตทางอินพุต x (หนึ่งบิตต่อหนึ่งคาบสัญญาณนาฬิกา) และให้เอาต์พุตเป็น 1 เมื่อพบลำดับที่กำหนด ในหัวข้อนี้จะออกแบบวงจรตรวจจับลำดับ “101” แบบซ้อนทับได้ (overlapping) หมายความว่าบิตท้ายของลำดับที่ตรวจพบแล้วนำไปเป็นบิตแรกของลำดับถัดไปได้ เช่น อินพุต 10101 จะตรวจพบ 2 ครั้ง เราจะออกแบบทั้งแบบ Moore และแบบ Mealy ด้วย D flip-flop แล้วเปรียบเทียบกัน

  3. ความเสถียรของเอาต์พุต — เอาต์พุตของ Moore คงที่ตลอดคาบ แต่เอาต์พุตของ Mealy เปลี่ยนตามอินพุตได้ทุกเวลา หากอินพุตมีสัญญาณรบกวนหรือเปลี่ยนค่าไม่พร้อมสัญญาณนาฬิกา เอาต์พุตอาจเกิดพัลส์แคบ ๆ ที่ไม่ต้องการ (glitch) จึงควรใช้ค่าเอาต์พุตของ Mealy ในช่วงก่อนขอบสัญญาณนาฬิกาเท่านั้น

10.4 ข้อควรพิจารณาด้านจังหวะเวลา

ในหัวข้อที่ผ่านมาเราถือว่าฟลิปฟลอปและเกตทำงานได้ทันที แต่ในวงจรจริงทุกองค์ประกอบมีเวลาหน่วง ซึ่งเป็นตัวกำหนดว่าวงจรทำงานได้เร็วที่สุดเท่าใด นอกจากนี้ยังต้องพิจารณาว่าวงจรจะทำงานได้ถูกต้องหรือไม่เมื่อเริ่มต้นจากสถานะที่ไม่ได้ใช้

10.4.1 Setup time, hold time และ propagation delay

ฟลิปฟลอปแบบ edge-triggered จะรับค่าอินพุตได้ถูกต้องเมื่อเป็นไปตามเงื่อนไขเวลาต่อไปนี้ (รูปที่ 10.20)

  • Setup time (tsu) — อินพุต D ต้องคงที่ก่อนขอบสัญญาณนาฬิกาอย่างน้อยเป็นเวลา tsu
  • Hold time (th) — อินพุต D ต้องคงที่หลังขอบสัญญาณนาฬิกาอย่างน้อยเป็นเวลา th
  • Propagation delay (tpd,FF) — เวลาตั้งแต่ขอบสัญญาณนาฬิกาจนเอาต์พุต Q เปลี่ยนเป็นค่าใหม่

หากละเมิด setup time หรือ hold time ฟลิปฟลอปอาจเก็บค่าผิด หรือเข้าสู่สภาวะเมตาเสถียร (metastability) ซึ่งเอาต์พุตค้างอยู่ระหว่างระดับ 0 และ 1 ชั่วขณะหนึ่ง

10.4.2 ความถี่สัญญาณนาฬิกาสูงสุด

พิจารณาเส้นทางสัญญาณจากฟลิปฟลอปตัวหนึ่ง ผ่านวงจรคอมไบเนชัน ไปยังอินพุต D ของฟลิปฟลอปอีกตัวหนึ่ง (รูปที่ 10.21) หลังขอบสัญญาณนาฬิกา เอาต์พุต Q จะเปลี่ยนเมื่อผ่านไป tpd,FF จากนั้นวงจรคอมไบเนชันใช้เวลา tcomb ในการคำนวณค่าใหม่ และค่าที่ได้ต้องมาถึงขา D ก่อนขอบสัญญาณนาฬิกาถัดไปอย่างน้อย tsu คาบสัญญาณนาฬิกา T จึงต้องสอดคล้องกับเงื่อนไข

T ≥ tpd,FF + tcomb(max) + tsu
fmax = 1 / (tpd,FF + tcomb(max) + tsu)

โดย tcomb(max) คือเวลาหน่วงของเส้นทางที่ยาวที่สุดในวงจรคอมไบเนชัน เรียกว่าเส้นทางวิกฤต (critical path) ส่วนเงื่อนไขของ hold time พิจารณาจากเส้นทางที่สั้นที่สุด คือ tpd,FF + tcomb(min) ≥ th เพื่อไม่ให้ค่าใหม่มาถึงขา D เร็วเกินไปจนทับค่าที่กำลังถูกเก็บ

10.4.3 สถานะที่ไม่ใช้และ self-starting

เมื่อจำนวนสถานะน้อยกว่า 2n จะมีรหัสที่ไม่ได้ใช้ ซึ่งในการออกแบบเรากำหนดให้เป็น don’t care แต่เมื่อจ่ายไฟเข้าวงจร หรือเมื่อมีสัญญาณรบกวน ฟลิปฟลอปอาจอยู่ในสถานะที่ไม่ใช้ได้ วงจรที่ดีจึงควรเป็นวงจรที่เริ่มทำงานได้เอง (self-starting) คือจากสถานะที่ไม่ใช้ใด ๆ วงจรจะเข้าสู่ลำดับการทำงานปกติภายในจำนวนคาบที่จำกัด ไม่ติดค้างอยู่ในวงวนของสถานะที่ไม่ใช้ ซึ่งเรียกว่าการล็อก (lock-up) วิธีตรวจสอบคือวิเคราะห์วงจรที่ได้ (ตามหัวข้อ 10.2) ที่สถานะที่ไม่ใช้ทุกสถานะ แล้ววาดลงในผังสถานะ

ตัวอย่างเช่น วงจรตรวจจับ 101 แบบ Mealy (ตัวอย่างที่ 10.5) มีรหัส 11 ที่ไม่ใช้ แทน Q1 = Q0 = 1 ลงในสมการ D1 = Q0x, D0 = x และ y = Q1x ได้ว่า เมื่อ x = 0 วงจรไปที่ 10 (S2) โดย y = 0 และเมื่อ x = 1 วงจรไปที่ 01 (S1) โดย y = 1 ดังรูปที่ 10.22 วงจรจึงเป็น self-starting โดยกลับเข้าสู่ลำดับปกติภายในหนึ่งคาบ (แต่อาจให้เอาต์พุต 1 ที่ผิดพลาดได้หนึ่งครั้ง หากต้องการป้องกันก็สามารถกำหนด y ที่สถานะ 11 เป็น 0 แทน don’t care) ในทำนองเดียวกัน สถานะที่ไม่ใช้ 0, 3, 4 และ 6 ของวงจรนับในตัวอย่างที่ 9.2 จะเปลี่ยนไปเป็น 0 → 3 → 4 → 7 และ 6 → 1 ซึ่งล้วนกลับเข้าสู่ลำดับการนับ

  • Mealy machine มีเอาต์พุตขึ้นกับสถานะและอินพุต (ป้ายลูกศร x/y) ส่วน Moore machine มีเอาต์พุตขึ้นกับสถานะเท่านั้น (เขียนเอาต์พุตในวงกลม) Mealy มักใช้สถานะน้อยกว่าและตอบสนองเร็วกว่าหนึ่งคาบ แต่เอาต์พุตเปลี่ยนตามอินพุตได้ตลอดเวลา
  • สมการคุณลักษณะ (Q+ = D, Q+ = T ⊕ Q, Q+ = JQ + KQ) ใช้ในการวิเคราะห์ ส่วนตาราง excitation ใช้ในการออกแบบ
  • การวิเคราะห์: สมการอินพุต/เอาต์พุต → สมการสถานะถัดไป → ตารางสถานะ → ผังสถานะ → ผังเวลาและความหมาย
  • การออกแบบ: ข้อกำหนด → ผังสถานะ → ตารางสถานะ → ลดสถานะ (เช่น จับคู่แถว) → กำหนดรหัส (ไบนารี เกรย์ one-hot) → ตาราง excitation → แผนผังคาร์โนห์ → วงจร → ตรวจสอบ
  • ความถี่สัญญาณนาฬิกาสูงสุด fmax = 1/(tpd,FF + tcomb(max) + tsu) โดยใช้เส้นทางวิกฤต และต้องตรวจ hold time ด้วยเส้นทางที่สั้นที่สุด
  • ต้องตรวจสถานะที่ไม่ใช้ทุกสถานะว่าวงจรเป็น self-starting หากพบ lock-up ให้กำหนดสถานะถัดไปของสถานะที่ไม่ใช้เองแทน don’t care
