ต่อยอดจากบทที่ 4 (วิเคราะห์วงจร) และบทที่ 5 (ลดรูป)

6.1.1วงจร AND-OR

รูปที่ 6.1

X = AB + CD

วงจรของนิพจน์ SOP: AND ทีละพจน์ แล้ว OR

ข้อสรุป: X = HIGH เมื่อ A และ B เป็น HIGH หรือ C และ D เป็น HIGH
ตารางที่ 6.1 มีคอลัมน์ผลระหว่างทาง AB และ CD — สอนให้ใส่คอลัมน์ระหว่างทางทุกครั้งที่วิเคราะห์

ตัวอย่างที่ 6.1: เตือนระดับสารเคมี 3 ถัง

ให้นักศึกษาออกแบบเองก่อน 3 นาที: ต้องการเตือนเมื่อต่ำ “สองถัง” → จับคู่ AB, AC, BC → OR · ถาม: ถ้าต่ำทั้งสามถังเตือนไหม?

6.1.2AND-OR-Invert

รูปที่ 6.2

X = AB + CD

= (AB)(CD) = (A + B)(C + D) → POS

ข้อสรุป: X = LOW เมื่อ A และ B เป็น HIGH หรือ C และ D เป็น HIGH (กลับค่าเอาต์พุตของตารางที่ 6.1)
AOI เป็นไอซีจริง เช่น 74LS51 (dual AND-OR-Invert) — ข้อมูลเสริม

ลองเอง: AND-OR ⇄ AND-OR-Invert

สลับโหมดแล้วให้สังเกตว่าคอลัมน์ X ของตารางกลับค่าทุกแถว

6.1.3–6.1.4XOR และ XNOR จากเกทพื้นฐาน

X = AB + AB = A ⊕ B

NOT 2 · AND 2 · OR 1 · HIGH เมื่ออินพุตต่างกัน

X = AB + AB

complement ของ XOR · HIGH เมื่ออินพุตเหมือนกัน
พิสูจน์ XNOR: complement(AB + AB) = (A + B)(A + B) = AB + AB (ตรงกับตัวอย่างที่ 4.7)

6.1.5สร้างวงจรจากนิพจน์บูลีน

X = AB + CDE → AND 2 อินพุต + AND 3 อินพุต → OR

X = AB(CD + EF) = ABCD + ABEF

รูป SOP มีจำนวนชั้นของเกทน้อยกว่า → propagation delay น้อยกว่า

ลำดับการปฏิบัติการ: NOT → AND → OR ตามโครงสร้างนิพจน์ · โยงบทที่ 3 หัวข้อ 3.7.6 เรื่อง delay สะสม

6.1.5สร้างวงจรจากตารางค่าความจริง

  1. หาแถวที่ X = 1 → พจน์การคูณ (1 = ตัวแปร, 0 = complement)
  2. OR ทุกพจน์ → นิพจน์ SOP
  3. (ลดรูปด้วยแผนผังคาร์โนห์ถ้าทำได้)
  4. วาดวงจร: inverter → AND → OR · เลือกไอซี

6.2วงจรคอมไบเนชันกับอินพุตที่เป็นพัลส์

ตัวอย่างที่ 6.6

ตารางค่าความจริงไม่เปลี่ยน แม้อินพุตเปลี่ยนตามเวลา

หาเอาต์พุตทีละช่วงเวลา ผ่านสัญญาณระหว่างทาง

X = A(B + C) = AB + AC

X = LOW เมื่อ A·B = 1 หรือ A·C = 1

ตัวอย่างที่ 6.7–6.9: ฝึกหาสัญญาณระหว่างทาง (Y1, Y2…) ก่อนหาเอาต์พุต

ลองเอง: ผังเวลาพร้อมสัญญาณระหว่างทาง

ตย. 6.7 คือ XNOR ที่สร้างจากเกท · คลิกเปลี่ยนรูปคลื่นอินพุตแล้วให้นักศึกษาทายเอาต์พุตก่อน

สรุปท้ายบท

  • AND-OR = SOP (X = AB + CD) · AND-OR-Invert = AB + CD ≡ POS (A + B)(C + D)
  • XOR = AB + AB (ต่างกัน) · XNOR = AB + AB (เหมือนกัน)
  • สร้างวงจรจากนิพจน์: แยกพจน์ย่อย → NOT → AND → OR
  • SOP ลดจำนวนชั้นของเกท → ลด propagation delay
  • จากตารางค่าความจริง: แถวที่ X = 1 → พจน์การคูณ → OR · ลดรูปด้วย DeMorgan / แผนผังคาร์โนห์
  • อินพุตเป็นพัลส์: ตารางค่าความจริงคงเดิม หาเอาต์พุตทีละช่วงเวลา
